# Voiceover (Arnav's rule from 2026-11-10: EVERY CLASS and REEL gets an ElevenLabs voiceover)
Approved reference: Class 01 voice version (male, energetic, Hinglish), built 2026-11-10.

1. Script: one short voice line per scene, written in Devanagari for the Hindi words + English words in Latin (e.g. "Product मत बेचो, problem बेचो।"). This gives natural Hinglish pronunciation. Keep the total voice at or under the video limit (CLASS ≤45 s, REEL ≤30 s); after trimming silence and 1.08x speed, ~2.3 Devanagari words/sec. No numbers as digits, write them as words ("पचास").
2. TTS via Zapier: execute_zapier_write_action, selected_api App226160CLIAPI, action text_to_speech, tool_name elevenlabs_convert_text_to_speech, connection_id 02f4e6d9-e8ba-82e3-bba2-5849c3f79bb9, params {text, voice_id: "TX3LPaxmHKxFdv7VOQHJ" (male energetic, approved), model_id: "eleven_multilingual_v2", output_format: "mp3_44100_128"}. One call per scene. Download audio_url with curl (zapier-dev-files.s3.amazonaws.com is allowlisted). The API key cannot list voices (no voices_read), so use the voice_id above.
3. Clean each clip: ffmpeg -af "silenceremove=start_periods=1:start_threshold=-45dB,areverse,silenceremove=start_periods=1:start_threshold=-45dB,areverse,atempo=1.08" -ar 48000 -ac 1 sN.wav
4. Time the video to the voice: each scene length = voice length + ~0.8–1.2 s (end card gets +1.2 s hold). Stretch the scene's animation timings to match (multiply local times by a per-scene factor K) so the text appears as it is spoken.
5. Mix: each clip with adelay=<scene start + 0.3 s>, amix normalize=0, loudnorm I=-15, music.py track at volume 0.55 ducked under the voice with sidechaincompress (threshold 0.03, ratio 6), AAC 192k 48 kHz, -c:v copy, -movflags +faststart. Check volumedetect: max around -4 dB, no clipping.
